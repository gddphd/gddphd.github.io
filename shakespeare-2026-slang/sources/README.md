# Source Register

This directory records the principal evidence and reference classes used by the Shakespeare 2026 Slang project. It intentionally does not redistribute every third-party source file.

## Shakespeare textual baselines

Primary textual comparison is against public-domain Shakespeare works using modern scholarly reference pages, especially the **Folger Shakespeare Library** online texts. Individual work READMEs identify act/scene scope and relevant Folger baselines.

Folger Shakespeare Library: <https://www.folger.edu/explore/shakespeares-works/>

## Contemporary slang lexicon

Primary supplied lexicon: **Dan Saltman, “Social Media Slang: Emoji and Acronym Meanings Teens are Using,” September 18, 2025.** Project copy: 55-page PDF captured/supplied August 30, 2026; 2,554,033 bytes; SHA-256 `a2804b186e39231b7849501d7660bf72a8e42b661015ca3430e593c72b6ef2d6`.

The PDF itself is not redistributed here. Terms used from it are classified as PDF-attested or PDF-attested variants; outside terms require separate contemporary support and labeling.

## External methodological review

Nine supplied PDFs attributed to Gemini were used to stress-test prosody, tone, rhyme, prose modality, pragmatic alignment, and methodological limits. Parsed review archives are stored at `../methodology/drasp-tests/reviews/`. They are development-history sources, not automatically controlling protocol rules.

## Evidence-status rule

The project distinguishes Shakespeare source language, translated/adapted language, source-attested slang, source-attested variants, supplemental contemporary usage, creative accommodation, external review, and project editorial judgment.
