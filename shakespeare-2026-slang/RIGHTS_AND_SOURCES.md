# Rights and Source Scope

This file clarifies the rights scope of the **Shakespeare 2026 Slang** project within the broader `gddphd.github.io` repository.

## Repository license and third-party material

The repository root currently carries a CC0 1.0 Universal dedication. That dedication should be understood to apply only to material for which the repository owner has authority to make that dedication. The presence of third-party text, citations, quotations, review material, source metadata, or analysis does **not** purport to relicense material owned by others.

This notice is a project provenance and reuse notice, not legal advice.

## Shakespeare source text

The underlying works of William Shakespeare are in the public domain in the United States. The project uses modern scholarly editions, especially Folger Shakespeare Library pages, as textual baselines and reference points. Editorial apparatus, annotations, website presentation, or other modern-edition material may have separate rights or terms and is not automatically dedicated to CC0 by this repository.
