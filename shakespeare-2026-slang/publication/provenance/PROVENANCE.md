# Project Provenance

## Scope

This record documents the provenance model for the Shakespeare-in-2026-Slang corpus and the Romeo Protocol used to construct and evaluate it.

## Source layers

### Shakespeare baseline

The adaptation documents identify Folger Shakespeare Library texts as the primary dramatic/source baseline for the scenes translated in the current corpus.

### Contemporary slang evidence

The primary slang lexicon used during the established translation workflow is the user-supplied PDF `Social Media Slang: Emoji and Acronym Meanings Teens are Using`. Selected current expressions absent from that glossary may be used only with separate contemporary support and explicit evidence labeling under the Romeo Protocol.

### Project-created transformation layer

The modernized dialogue, annotations, lexical systems, scene ledgers, prosodic analyses, protocol rules, DRASP synthesis, and editorial apparatus are project-created derivative/editorial material. Shakespeare's underlying public-domain text and the project's original transformation layer must not be conflated for licensing or attribution purposes.

### External AI review layer

The project owner supplied several external reviews attributed to Gemini. Those reviews contributed stress-test hypotheses and methodological criticism. Revision B-D credit Gemini for those originating observations while separately identifying the Romeo Protocol's later formalization, evidence qualification, and cumulative integration.

## Version lineage

The project follows preservation-first versioning:

- The original *Romeo and Juliet* II.ii adaptation remains the methodological origin artifact.
- *A Midsummer Night's Dream* dossier preserves superseded drafting layers within the dossier rather than deleting them.
- *Othello*, *King Lear*, and *The Tempest* v1.0 working editions remain historical artifacts even if later retro-audits produce successors.
- Romeo Protocol v2.0 drafts are cumulative: initial Nuance-Fidelity draft -> Revision B -> Revision C -> Revision D.
- Revision D remains a draft candidate until explicitly adopted.

## Canonical versus historical counts

Superseded translations are retained for provenance but do not enter current canonical corpus totals unless a historical-production metric is specifically reported. This prevents rewritten passages from being double-counted.

## Repository staging rule

Project organization is being performed on the `shakespeare-2026-slang-setup` branch. Nothing in this provenance file authorizes merging into `main` or changing the public GitHub Pages site.

## Licensing

The project-specific license remains unresolved. The existence of a repository-level LICENSE file must not be treated as a determination that it governs every newly organized adaptation, annotation, protocol, review, or derived artifact. A project-specific licensing decision should be made explicitly before formal public release.
